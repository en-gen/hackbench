### Added

- Maps, Graphics, Palettes and Audio explorers can be searched: press Ctrl+F or the Find button, then type to filter by number (`109`, `$109`, `0x109`, `1fc`) or part of a name (spaces allowed). Enter opens the selected match, Up and Down step through matches, and Escape clears the filter and puts every folder back open or closed as it was before. Maps also match a map's name from the project's map aliases, and every explorer matches a row's id text exactly as it is drawn, decimal or hex.
