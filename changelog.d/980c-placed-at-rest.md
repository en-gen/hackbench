### Changed

- Map view: each sprite is drawn at the position in the map's sprite list, with the look its start-up code gives it (tiles, flips, variants), so the P-switch and the Pokey now show their pictures. The moves that start-up code makes are left for play/simulate, so nothing shifts. Sprites that put no picture on screen after start-up, such as 7 chainsaws and 3 grinders on the vanilla maps, show the not-drawn marker with the reason (#980).
