### Changed

- Internal: the stock-code gate that decides whether the overworld entry path and the level-start code are the game's no longer spells any game code bytes (#1061). The overworld guard, table load and CODE_05D8A2 block are checked as single named opcodes with their branch targets read from the ROM; the guard and the index computation, and the secondary-exit branch and the main index with their neighbors, each merge into one digest of at least 24 unknown bytes. Evidence: same accepted and refused results, entry bias and entrances on 7 ROMs in the corpus directory and 586 other ROMs (one machine); the new opcode and digest checks are swept in synthetic tests and go red when a byte is changed. Operands that name a RAM address are no longer compared.
