### Changed

- Internal: the stock-code gate that decides whether the overworld entry path and the level-start code are the game's now states far less game code (#1061). The overworld guard, table load and CODE_05D8A2 block are checked as single named opcodes; the guard and the index computation, and the secondary-exit branch and the main index with their neighbors, each merge into one digest of at least 24 unknown bytes. Short stated runs remain (the entry call, the entry jump, the screen-exit lookups), left for #1109. Evidence, one machine: 877 unique ROMs, about 150 SMW-based (122 pass the entry path on both gates, with the same threshold, bias and high byte), 0 verdict differences. The new opcode and digest checks are swept in synthetic tests and go red when a byte is changed. The seven RAM addresses those instructions name are compared against a named table, a ruled D126 exception for this block only (D185); the threshold, bias and high byte are still read from the ROM, the three branch displacements sit in one digest of 84 unknown bytes, with an 83-byte variant for Lunar Magic's site hook (no distance is stated, though the op addresses let a reader derive them until #1109 lands), and a hack that keeps the opcodes but repoints a store is refused, as on develop.
