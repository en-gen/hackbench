### Changed

- Internal: the stock-code gate that decides whether the overworld entry path and the level-start code are the game's now states far less game code (#1061). The overworld guard, table load and CODE_05D8A2 block are checked as single named opcodes with their branch targets read from the ROM; the guard and the index computation, and the secondary-exit branch and the main index with their neighbors, each merge into one digest of at least 24 unknown bytes. Short stated runs remain (the entry call, the entry jump, the screen-exit lookups), left for #1109. Evidence, one machine: of 877 unique ROMs compared check by check, 122 pass the whole entry path under both the old and new gates with the same threshold, bias and high byte; 0 verdict differences. The new opcode and digest checks are swept in synthetic tests and go red when a byte is changed. The seven RAM addresses those instructions name are compared against a named table, a ruled D126 exception for this block only (D185); the threshold, bias, high byte and displacements are still read from the ROM, and a hack that keeps the opcodes but repoints a store is refused again.
