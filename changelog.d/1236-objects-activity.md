### Added

- Objects activity (#1236): a new Objects view in the left sidebar, after Audio, to build, name and save Object definitions. Pick a tileset, choose Edge or Fill, and click that tileset's Map16 tiles to tag them (a click replaces the tile's other role; clicking again untags it). Two lists show the tagged tiles, a preview color select tries other palettes without saving them, and Save, Rename and Delete keep one file per Object in the project's `meta/objects/`, never in the ROM. A file that cannot be read (damaged, another version, a tileset or tile this ROM does not have) shows a plain-words note and the rest still load. Format: `docs/architecture/object-definitions.md`. Synthetic unit tests (no ROM) sweep every skip reason and prove a save that drops the fill list turns red.
