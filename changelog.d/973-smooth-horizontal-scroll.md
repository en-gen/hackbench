### Fixed

- Maps view (#973): scrolling a long horizontal map no longer stutters. Every scroll event rebuilt the picture of each screen that has no block indicators (about 44 ms per event on slot `$105`); a screen found to have none now keeps that result until its key changes. Evidence: slot `$105` of the vanilla ROM, `build:browser`, Playwright 1.63 headless Chromium, one Windows machine, mouse wheel (assumed held-tilt rate of 30 events per second, not a measured device) and scrollbar thumb drag, zooms fit and 1x to 4x, 3 spec runs. With the fix: frame p50 16.7 ms and p95 16.8 ms, longest frame 16.8 ms, longest frozen span 50.1 ms (wheel) and 33.4 ms (drag), 0 display rebuilds. Without it: frame p95 50.1 to 100.0 ms, longest frame up to 116.6 ms, longest frozen span 66.6 to 116.7 ms, 396 to 1152 rebuilds. Electron and a real tilt wheel are not covered.
