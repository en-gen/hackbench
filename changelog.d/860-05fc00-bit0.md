### Fixed

- Maps (#860): the secondary entrance that targets a sublevel is now found by the game's own rule, destination map = (entrance index bit 8) then DATA_05F800 low byte (bank_05.asm:7103-7118). It had used bit 0 of DATA_05FC00, which is the entrance screen, as the map's high byte, so a hack whose entrance screens were odd could name the wrong entrance for Layer 2 and Layer 3 start positions. Evidence: synthetic sweep of all 256 DATA_05FC00 values (`SecondaryEntranceTarget.synthetic.test.ts`, red 3 of 3 before the fix); the corpus expectations for `$102` and `$111` are unchanged.
