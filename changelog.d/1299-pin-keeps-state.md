### Changed

- Double-clicking a map that a preview tab is showing now pins it with that preview's palace and switch presses and its layer, sprite, grid and collision toggles, and the pinned map draws in that state. A map that already has a pinned tab keeps that tab's own presses, and a pin for a map the preview is not showing starts with defaults. Zoom and scroll are not carried: the pinned tab opens fitted at the map's start (#1299).
