### Added

- Map view: the saved Objects of a map are found and selectable, read-only (#1237). Hover shows a faint dashed outline and a light tint; a click selects the whole Object with one outline and a light tint, never a box per tile; on a selected Object the edge segments can be hovered and selected, Ctrl+click adding more, and a run of slope tiles at one angle is one segment. Objects are found from the stored pieces (a covered Object whole, touching Objects apart) and from visible tiles, from the definitions in `meta/objects/`; a map with per-map tiles says so in plain words. Evidence: synthetic cases for the matching rule, a swept hill, a four-platform stack in 60 piece orders and the planted drop of the piece split; vanilla `$103` screen 0 finds its four platforms; recognition on `$105` takes about 7 ms warm (one machine).
