- Maps view: Layer 3 is now drawn on maps $011, $130 and $1C1, which had a "camera-locked layer 3" toggle that was disabled (#563). In the game this layer follows the map, so it is drawn tiled every 512 px across the map from the camera at level load, with the translucency the game uses, and its tooltip says the real layer also drifts slowly to the left. Map $018 stays undrawn. Evidence: a trace of the game's Layer 3 handler and per-frame scroll, and a check of the layers_v5 captures at frame 0 for these three maps (Y, camera X and tilemap match exactly); one machine, vanilla ROM. A ROM that patches the camera code gets no drawing (the routines are fingerprinted). A map entered by a screen exit may load with a different camera than a direct load, so the entrance position keeps its "unverified" note.
