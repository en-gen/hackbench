### Changed

- The map view's red "!" mark on a Layer 1 object HackBench could not draw now shows a small red count badge in the tile's top-right quadrant when the object has more than one issue, and its tooltip lists every issue instead of one (#1005). A single issue looks as before. The count is the number of places in the object's drawing code that HackBench checked and found changed, so it can undercount a heavily changed object.
