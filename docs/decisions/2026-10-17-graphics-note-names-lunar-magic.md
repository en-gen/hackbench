# The graphics note keeps the Lunar Magic wording

## Question

The note "Graphics may not match the game" says the ROM picks graphics through Lunar Magic's list, which HackBench does not read. Keep naming Lunar Magic?

## Options considered

1. Keep "Lunar Magic" in the note.
2. Say "a list added by another editor" and leave the tool unnamed.

## Ruling

wording not recorded. Option 1 is what the mockup shows. `[INF]` Not ruled as a call; owner review pending.

## Why

The user needs to know which tool made the ROM behave this way. The note states what the ROM contains; it does not use Lunar Magic as a data source.
