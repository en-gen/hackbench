# Whole-ROM notes are shown once

## Question

Some notes are true of the whole ROM (the map entrance code is replaced, the graphics list is not read). Do they mark every map, or appear once?

## Options considered

1. Repeat the note on every map it affects.
2. Show it once under "This ROM" in Notes and Problems, counted once in the status bar.

## Ruling

wording not recorded. Option 2 is implied by the mockup the owner picked (D111, 2026-10-17). `[INF]` Not ruled as a call; owner review pending.

## Why

The same warning on every map is noise and inflates the warning count. A note about the ROM belongs to the ROM.
