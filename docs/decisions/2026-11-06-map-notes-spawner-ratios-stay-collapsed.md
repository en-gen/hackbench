# Per-spawner ratio sentences in a map note stay collapsed

## Question

When several spawners on one map each say "Only N of 5 appear" or "The spawner made N", should the map note sum them into one total?

## Options considered

A. Sum the ratios into one map-wide figure.
B. Keep each ratio as its own sentence, collapsed through the Set.

## Ruling

wording not recorded. 2026-11-06: night-shift call by the tech lead, awaiting the owner's ruling; option B is what [PR #1300](https://github.com/en-gen/hackbench/pull/1300) built (merged at 60409468), as [PROP]. It is not an owner ruling. [INF]

## Why

- Each ratio describes one spawner ("N of 5" is that spawner's cap), not a map total. A sum would turn two different ratios into a figure that matches neither.
- Only "N did not draw" is a plain count, so only it sums, per noun ([#1281](https://github.com/en-gen/hackbench/issues/1281)).
- If overruled for A: the ratio sentences need a combined wording, since "N of 5" has no meaning across spawners with different caps.

## Applies to

Map note text for spawner ratios only. Not the "did not draw" counts. Promotion to Ruled is the owner's.
