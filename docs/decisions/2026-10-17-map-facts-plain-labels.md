# Plain labels for three header fields

## Question

Which words does the Properties panel use for header fields whose ROM names are jargon?

## Options considered

1. Keep the ROM names: Level mode, Item memory, Object tileset.
2. Plain words: Layout, Collected items remembered, Tile graphics. The other fields keep their near-plain names.

## Ruling

wording not recorded. Option 2 is what the mockup shows and the owner picked (D111, 2026-10-17). `[INF]` Not ruled as a call; owner review pending.

## Why

UI principle: approachable first, ROM terms and hex only on request. The old-to-new mapping is the table in the design doc.
