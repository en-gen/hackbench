# A missing base ROM is a project problem, not a map note

## Question

When the base ROM is not on this machine, is that a note on each map?

## Options considered

1. A note on every map.
2. A project-level problem, outside the map notes and their count.

## Ruling

wording not recorded. Option 2 is stated for all three layouts in the mockup. `[INF]` Not ruled as a call; owner review pending.

## Why

No map can be read without the ROM, so a per-map note says nothing the project problem does not. It also keeps the map note count about maps.
